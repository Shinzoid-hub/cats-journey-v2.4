# Cat’s Journey V2 — Forest Whispers · Stage 2.3

Это отдельный проект новой версии. Старый проект и его Firebase не подключены и не изменяются.

## Запуск
1. Распакуй архив в отдельную папку.
2. Открой папку в VS Code и запусти `index.html` напрямую или через Live Server.
3. На ПК: WASD или стрелки, взаимодействие — E / Enter.
4. На телефоне: экранные стрелки и кнопка «Действие».

## Что добавлено в Stage 2.3
- Кнопка «Рейтинг» в верхней панели и список 10 лучших времён.
- Таймер прохождения; время сохраняется при закрытии страницы и продолжает идти после возвращения в игру, не считая время вне игры.
- Все 50 рыбок нельзя собирать, пока игрок не поговорит с Луной и не примет задание.
- Все 3 лунных осколка нельзя собирать, пока игрок не поговорит с Рыжиком и не примет его задание.
- После сбора 50 рыбок появляется сундук у извилистой тропинки и текст-подсказка вернуться по дороге.
- Открытие сундука завершает забег, сохраняет рекорд, показывает экран победы с короной и временем прохождения.
- Кнопка «Играть снова» начинает новый забег, не удаляя список рекордов.
- Автосохранение позиции, заданий и собранных предметов в `localStorage`.
- Адаптивные кнопки для ПК и телефона.

## Важно: рейтинг и сохранения
Рейтинг в этой сборке работает **локально на одном устройстве и в одном браузере**. Подруги, открывающие ссылку на своих телефонах, пока не будут видеть общий список рекордов. Для общего онлайн-рейтинга нужен отдельный backend — например, новый Firebase-проект с Firestore и анонимной авторизацией. Его настройки нужно добавить отдельно; старый Firebase не используется.

Прогресс сохраняется в браузере и на конкретном устройстве. Он не синхронизируется между телефоном и ПК. Для публичного тестирования опубликуй содержимое этой папки в отдельном GitHub-репозитории и включи GitHub Pages.

Визуальная часть рисуется Canvas-кодом; готовых спрайтов пока нет. Архив проверен на целостность, JavaScript — на синтаксические ошибки. Игровой процесс всё ещё нужно проверить в реальном браузере и на телефоне.
